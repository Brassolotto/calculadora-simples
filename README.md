# Calculadora Simples em Python

## 📝 Descrição
Uma calculadora em linha de comando que realiza as quatro operações básicas (adição, subtração, multiplicação e divisão). O programa foi desenvolvido em Python puro, sem uso de frameworks externos.

## 🚀 Funcionalidades
- Realiza operações matemáticas básicas (+, -, *, /)
- Interface via linha de comando
- Tratamento de erros para entradas inválidas
- Formatação de resultados com duas casas decimais
- Opção de sair do programa a qualquer momento

## 📋 Pré-requisitos
- Python 3.6 ou superior instalado

## 🔧 Como executar
1. Clone este repositório:
```bash
git clone https://github.com/Brassolotto/calculadora-simples.git
```

2. Navegue até o diretório do projeto:
```bash
cd calculadora-simples
```

3. Execute o programa:
```bash
python calculadora.py
```

## 📖 Como usar
1. Digite o primeiro número quando solicitado
2. Digite o segundo número
3. Escolha a operação desejada usando os símbolos:
   - `+` para adição
   - `-` para subtração
   - `*` para multiplicação
   - `/` para divisão
4. Para sair do programa, digite 'sair' quando solicitado o primeiro número

## 🎯 Exemplos de uso
```
Calculadora Simples
Digite 'sair' para encerrar

Digite o primeiro número: 10
Digite o segundo número: 5
Digite a operação (+, -, *, /): +

Resultado: 15.00
```

## ⚠️ Tratamento de Erros
O programa inclui tratamento para:
- Divisão por zero
- Entradas não numéricas
- Operadores inválidos

## 🔍 Estrutura do Código
```
calculadora.py
├── função calcular() - Processa as operações matemáticas
├── função main() - Controla o fluxo principal do programa
└── Dicionário de operações - Mapeia operadores para funções
```
